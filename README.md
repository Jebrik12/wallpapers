# Gradientora Wallpapers CDN

A collection of 1003 high-quality compressed gradient wallpapers organized across 55 categories.

## 🚀 CDN Usage

You can directly embed or fetch wallpapers in your web application using free high-speed CDNs:

### 1. jsDelivr (Recommended)
```
https://cdn.jsdelivr.net/gh/Jebrik12/wallpapers@main/{category}/{filename}
```
**Example:**
```html
<img src="https://cdn.jsdelivr.net/gh/Jebrik12/wallpapers@main/3d-chrome/3d-chrome-01.jpg" alt="3D Chrome Wallpaper" />
```

### 2. Statically CDN
```
https://cdn.statically.io/gh/Jebrik12/wallpapers/main/{category}/{filename}
```

### 3. Wallpaper Manifest API
All categories and asset paths are indexed in [`manifest.json`](manifest.json):
```javascript
const response = await fetch("https://cdn.jsdelivr.net/gh/Jebrik12/wallpapers@main/manifest.json");
const data = await response.json();
console.log(data.categories);
```
